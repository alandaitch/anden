# Seguridad

La seguridad y privacidad de Andén son prioritarias.

## Cómo reportar una vulnerabilidad

No publiques vulnerabilidades mediante Issues o Discussions.

Usá el [reporte privado de GitHub](https://github.com/alandaitch/anden/security/advisories/new).

Incluí solamente:

- Impacto observable.
- Pasos mínimos para reproducirlo.
- Navegador, sistema y versión afectada.
- Evidencia sin datos personales.

No incluyas credenciales reales, tokens ni ubicaciones personales.

## Alcance responsable

Limitá las pruebas a tus propios datos y sesiones.

No accedas a cuentas, dispositivos o información de terceros.

No interrumpas servicios ni automatices tráfico abusivo.

No existe una recompensa garantizada.

El código productivo no se distribuye desde este repositorio.
