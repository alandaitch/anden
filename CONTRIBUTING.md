# Cómo participar

Gracias por mejorar Andén.

Este repositorio recibe aportes comunitarios sin exponer el código productivo.

## Reportes útiles

Incluí pasos reproducibles, dispositivo, navegador y resultado esperado.

Usá estaciones, paradas o zonas públicas como referencia.

No compartas tu domicilio ni coordenadas personales.

En problemas de datos, agregá una fuente oficial cuando exista.

## Propuestas

Describí primero la necesidad del usuario.

Evitá exigir una implementación específica.

El equipo evaluará alcance, privacidad, costos y fuentes disponibles.

## Cambios documentales

Los pull requests sólo pueden modificar documentación comunitaria.

No envíes código, datos derivados, pruebas ni integraciones.

Cada aporte debe ser original y publicable por su autor.

## Conducta

Aplicamos [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
