# Cómo participar

Gracias por ayudar a mejorar Andén.

Este repositorio recibe aportes comunitarios sin distribuir el código productivo.

## Elegí el canal correcto

- Usá Issues para problemas concretos y reproducibles.
- Usá Discussions para preguntas e ideas tempranas.
- Usá pull requests para documentación y contratos públicos.
- Usá el reporte privado para vulnerabilidades.

La guía completa está en [Soporte y reportes](SUPPORT.md).

## Reportes útiles

Un buen reporte incluye:

1. El resultado observado.
2. El resultado esperado.
3. Pasos simples para reproducirlo.
4. Dispositivo, sistema y navegador.
5. Una referencia pública aproximada.
6. Una fuente oficial, cuando corresponda.

Usá estaciones, paradas o zonas públicas como referencia.

No compartas domicilios ni coordenadas personales.

Tampoco compartas credenciales, tokens o capturas con datos privados.

## Problemas de transporte

Indicá el tipo de transporte y servicio afectado.

Para colectivos, aclarar línea, ramal y sentido ayuda mucho.

Para trenes y subtes, indicá línea, estación y sentido.

Para EcoBici, usá el nombre público de la estación.

## Propuestas

Describí primero la necesidad del usuario.

Explicá qué situación concreta querés resolver.

Podés proponer una solución, pero no es obligatoria.

El equipo evaluará alcance, privacidad, costos y fuentes disponibles.

## Pull requests públicos

Los pull requests pueden modificar documentación, esquemas y ejemplos públicos.

Los esquemas deben describir contratos públicos sanitizados.

Los ejemplos deben ser mínimos, ficticios y no identificables.

No envíes código productivo, datos derivados ni integraciones.

Tampoco envíes información técnica interna ni credenciales.

Mantené cada pull request enfocado en un único cambio.

Revisá enlaces y ortografía antes de enviarlo.

Ejecutá `npm ci` y `npm test` antes de enviar cambios.

Cada aporte debe ser original y publicable por su autor.

## Revisión

Un reporte aceptado no garantiza implementación ni fecha.

La prioridad depende del impacto, alcance y evidencia disponible.

Aplicamos el [Código de conducta](CODE_OF_CONDUCT.md).
