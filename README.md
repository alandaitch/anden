# Andén

**El transporte cercano, explicado simple.**

[Abrir Andén][app] · [Reportar un error][bug] ·
[Proponer una mejora][suggestion] · [Conversar][discussions]

Andén reúne información útil del transporte público del AMBA.

La aplicación prioriza opciones cercanas y tiempos relevantes.

Incluye colectivos, trenes, subtes y estaciones EcoBici.

Los datos pueden ser en vivo o programados.

Andén identifica esa diferencia cuando la fuente lo permite.

## Cómo participar

No necesitás saber programar.

- Si algo funciona mal, [reportá un error][bug].
- Si falta una línea, [reportá el transporte faltante][missing].
- Si un dato es incorrecto, [reportá el problema][data].
- Si tenés una idea, [proponé una mejora][suggestion].
- Si querés explorarla, [abrí una conversación][discussions].
- Si encontraste una vulnerabilidad, [reportala en privado][security].

Una referencia pública facilita muchísimo la revisión.

Puede ser una estación, parada, línea o enlace oficial.

No publiques domicilios, coordenadas personales, credenciales ni datos privados.

Encontrá ejemplos y criterios en [Cómo participar](CONTRIBUTING.md).

## Qué contiene este repositorio

Este repositorio funciona como espacio comunitario y documental.

Acá se reciben reportes, propuestas y mejoras documentales.

El código productivo de Andén no se distribuye actualmente.

Los pull requests deben limitarse a documentación comunitaria.

## Información importante

Andén es un proyecto independiente y sin garantías.

La cobertura depende de fuentes externas y operadores oficiales.

Verificá siempre la información crítica con el operador correspondiente.
